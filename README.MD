# Rosis Sharma Resume

## Description

A modern and responsive online resume built with HTML and CSS, showcasing personal information, skills, education, projects, and references. The projects section includes clickable GitHub links for React projects.

## Features

- Responsive design for desktop and mobile screens
- Projects section with GitHub links
- Organized sections for Skills, Education, Contact, and References
- Clean layout with icons for email and phone

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- Google Fonts
- Material Symbols Outlined (icons)

## How to Use

1. Clone or download the repository.
2. Open `index.html` in a web browser.
3. Update the HTML or CSS files to customize personal information, projects, or styling.
